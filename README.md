# homework_bot-vk
Python VK bot, который обращается к API сервиса Яндекс.Практикум Домашка и узнает статус отправленной на ревью домашней работы.

## Ключевые возможности
* Работает в фоновом режиме, опрашивая API Практикума каждые 10 минут.
* Присылает точное название домашней работы и статус проверки.
* При возникновении сетевых ошибок и падении API бот пришлет отчет об ошибке в VK.

## Технологический стек
* **Язык разработки:** Python 3.14
* **Библиотека VK API:** vk_api
* **Сетевые запросы:** requests
* **Конфигурация:** python-dotenv

## Подготовка (Токены)
1. **VK Токен:** Создайте сообщество VK, перейдите в *Управление -> Работа с API* и сгенерируйте ключ доступа (с правами на `Сообщения`).
2. **Ваш VK_USER_ID:** Узнайте свой цифровой ID профиля (например, через специализированные сервисы), чтобы бот знал, кому слать сообщения.
3. **Практикум Токен:** Получите OAuth-токен Практикума

## Инструкция по установке и запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/ElviraKamalova/homework-bot-vk-new.git
cd homework-bot-vk-new
```

### 2. Создание и активация виртуального окружения
* **Для Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```
* **Для Windows:**
```bash
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации
Создайте файл `.env` в корне проекта.
Заполните его вашими данными:
```env
VK_TOKEN=ваш_токен_сообщества_vk
PRACTICUM_TOKEN=ваш_oauth_токен_практикума
VK_USER_ID=ваш_цифровой_id_в_vk
```

### 5. Запуск
* **Для Linux/macOS:**
```bash
python3 homework.py
```
* **для Windows:**
```bash
python homework.py
```
